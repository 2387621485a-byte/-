# 2026年618考试 - 在线答题系统

这是一个基于纯前端技术开发的在线答题系统，包含30道关于照明产品知识的考试题目。

## 功能特点

- ✅ 30道题目（判断题10道、多选题14道、单选题6道）
- ⏱️ 60分钟倒计时功能
- 📊 实时答题进度显示
- 🎯 自动评分系统
- 📝 错题标注和正确答案展示
- 📱 响应式设计，支持多设备访问

## 在线访问

直接打开 `exam.html` 文件即可开始答题。

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)

## 使用说明

1. 打开网页后自动开始计时
2. 依次回答30道题目
3. 点击"提交试卷"按钮查看成绩
4. 系统会自动标注正确和错误的答案
